### О проекте
Эмулятор виртуальной файловой системы представляет собой графическую оболочку (GUI), имитирующую работу консоли.  
Он обрабатывает команды `ls`, `cd`, `echo`, `exit`, выполняет подстановку переменных окружения и может запускаться с заранее подготовленными скриптами.  

Цель проекта — реализовать функциональность **Этапов 1 и 2**, предусмотренных практической работой:
- **Этап 1:** реализация базового интерфейса (GUI + REPL) и обработка команд-заглушек;  
- **Этап 2:** добавление параметров запуска (`--vfs-path`, `--start-script`) и автоматического выполнения скриптов.

---

## 2. Описание функций и настроек

### Основные команды
| Команда | Описание |
|----------|-----------|
| **ls [путь]** | Вывод содержимого (демонстрационный, не обращается к реальной файловой системе). |
| **cd путь** | Изменение текущего каталога (пока не влияет на файловую систему). |
| **echo [текст]** | Вывод текста с подстановкой переменных окружения (`$HOME`, `${USER}`, `~`). |
| **exit** | Завершение работы программы. |

---

### Дополнительные возможности
- **Раскрытие переменных окружения**  
  Поддерживаются `$VAR`, `${VAR}`, `~`.  
  Пример: `echo $HOME` → `C:\Users\Имя`.

- **Обработка ошибок**  
  Программа сообщает пользователю об ошибках:
  - неизвестная команда;
  - неверное количество аргументов;
  - ошибка разбора кавычек.

- **Комментарии в скриптах**  
  Любая строка, начинающаяся с `#`, игнорируется, но выводится в GUI для удобства.

### ⚙️ Настройки и аргументы запуска (Этап 2)
Эмулятор поддерживает два аргумента командной строки:

| Аргумент | Назначение |
|-----------|-------------|
| `--vfs-path <путь>` | Путь к виртуальной файловой системе (используется для отладочного вывода). |
| `--start-script <файл>` | Путь к стартовому скрипту, выполняемому при запуске. |

Пример запуска:
```bash
python emulator_gui_stage2.py --vfs-path "C:\Users\you\vfs_example" --start-script start_stage2_full.txt
